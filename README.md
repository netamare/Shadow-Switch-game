# Shadow Switch

Shadow Switch is a puzzle game where you switch between the **Real World** and **Shadow World** to solve puzzles and reach the exit.

Each world has different obstacles, traps, and paths, so you need to think carefully about when to switch.

## Features

* 5 challenging levels
* Real and Shadow worlds
* Keyboard controls
* Puzzles, traps, and enemies
* Score, lives, and timer
* Help / How to Play page
* Dark and light mode
* Progress saving

## Built With

* React
* JavaScript
* CSS

Have fun switching between worlds!
